# Local Intelligence Hub (LIH)

## 개요
LIH는 로컬 파일을 AI로 분석하는 지능형 데스크톱 어시스턴트입니다.
FastAPI 백엔드와 React 프론트엔드, Tauri 데스크톱 앱으로 구성되어 있습니다.

## 주요 기능
- 파일 인텔리전스: 폴더 스캔 후 AI가 정리 계획 생성
- 지식 엔진: 로컬 파일 인덱싱 및 RAG 기반 질의응답
- 학습 엔진: 인덱싱된 문서에서 개념/질문/면접 자동 생성

## 기술 스택
- Backend: Python 3.11, FastAPI, ChromaDB, SQLite
- Frontend: React, TypeScript, Vite, TailwindCSS
- Desktop: Tauri v2 (Rust)
- LLM: OpenAI / Ollama / Gemini 멀티 프로바이더
- Embedding: Ollama nomic-embed-text / OpenAI text-embedding-3-small
